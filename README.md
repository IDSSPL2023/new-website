# Obsidian Banking

REDESIGN THE IDSSPL WEBSITE USING THE PROVIDED IDSSPL WEBSITE AS THE CONTENT SOURCE AND OBSIDIAN (https://obsidianos.com/) AS THE VISUAL / UX REFERENCE.

REFERENCE STYLE:
https://obsidianos.com/?ref=saaspo.com

CURRENT WEBSITE:
https://idsspl.com/

IMPORTANT:
DO NOT COPY OBSIDIAN'S CONTENT, BRANDING, LOGO, COLORS, IMAGERY, OR EXACT UI.

Take inspiration from its:

Premium editorial layout

Oversized typography

Minimal navigation

Strong whitespace

Product-led storytelling

Large visual sections

Smooth scroll transitions

Sophisticated product mockups

Subtle animation

Clean information hierarchy

Enterprise SaaS aesthetic

Then reinterpret that design language specifically for IDSSPL as a premium banking technology company.
